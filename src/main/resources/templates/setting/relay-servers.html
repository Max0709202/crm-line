  1. 「使用中」のリレーを 優先順位の上から順 に見て、ユーザーが 対象条件（フォルダ・入金回数）に当てはまる最初のリレー で送信します。条件なしのリレーは 全対象 です。
  2. ⚠ どのリレーにも当てはまらない／使用中が0件 → 本サーバの postfix から直接配信（MX ルックアップ）。迷惑メール判定・到達率低下のおそれがあります。
  3. リレーのIPが （HTTP-bridge転送機）なら SSH+HTTP API 方式、それ以外は直接 SMTP で配送します。
